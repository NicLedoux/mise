# RECIPE SHARING APP

### A Full-stack MERN web app for recipes

This repo is where I house my full-stack recipe sharing app developed while pursuing a post-graduate degree at Ball State Univeristy.
The app uses the following:

- MERN Stack using: - MongoDB - Express.js - React - Node.js
  The web app includes the following features:
- Users can login and post/manage their own recipes
- Users can 'Like' recipes
- Users can sort recipes by popularity
